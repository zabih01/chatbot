# Chatbot

**A private, locally hosted AI chatbot powered by Ollama and open-source LLMs.**

Run AI directly on your machine without relying on external APIs. Simple, fast, extensible, and built with privacy in mind.

## Features

* Local LLM inference with Ollama
* Private conversations
* No external API keys required
* Clean and extensible architecture
* Easy to configure and run

## Tech Stack

`Ollama` · `LLMs` · `Python`

## Quick Start

```bash
git clone https://github.com/your-username/chatbot.git
cd chatbot

ollama pull llama3.2
```

Then start the application and begin chatting with your local AI model.

## Vision

A lightweight foundation for building powerful AI applications with local language models.
